# Luma E-Commerce Website - Automated Testing with Katalon Studio

This repository contains automated **test cases** for the **Luma E-Commerce Website**, built using **Katalon Studio**.  
The tests are focused on validating key user flows to ensure that core functionalities of the website work as expected.  

## 📝 Features Tested
The automated test cases cover the following scenarios:
- User login  
- Product search  
- Add to cart  
- Checkout functionality
